## Introduction & Purpose

**IAcine Virtual Avatar** is an advanced AI-powered assistant designed to bring human-like interactions to life. This project showcases a 3D animated avatar capable of intelligent, natural conversations, making it ideal for professional scenarios like mock interviews, interactive demos, or virtual companionship. 🧑‍💻🤝

With **IAcine Virtual Avatar**, experience the seamless integration of the local language model **Llama3.2:b** and **ElevenLabs API** for voice synthesis, combined with 3D animation crafted using **Blender**, ensuring a visually stunning and immersive experience. 🚀✨



## Features

- 🧑‍🎤 **Realistic 3D Avatar**: Designed and animated in Blender for lifelike movements and expressions.
- 💬 **AI-Driven Conversations**: Powered by Llama3.2:b for intelligent and natural responses.
- 🔊 **Natural Voice Integration**: High-quality, realistic voice synthesis using ElevenLabs API.
- 📈 **Customizable Prompts**: Tailored for professional or creative use cases like interviews or Q&A.
- 🔒 **Local Model Execution**: Ensures data privacy by running everything on your machine.



## Technologies Used

- 🐍 Python 3.12
- 🧠 Local Language Model: Llama3.2:b
- 🔊 ElevenLabs API: Advanced voice synthesis
- 🎮 Three.js & React-Three-Fiber: 3D avatar rendering
- 🎨 Blender: For 3D modeling, rigging, and animation
